# STARFLASH ⭐
### AI-Based Student Distraction Detection System

STARFLASH is a computer vision-based student attention monitoring system developed using Python, Flask, OpenCV and MediaPipe.

## Features
- Face detection and monitoring
- Student attention analysis
- Focused and distracted student tracking
- Distraction event monitoring
- Attention analytics dashboard
- Web-based student interface

## Technologies Used
- Python
- Flask
- OpenCV
- MediaPipe
- NumPy
- HTML, CSS and JavaScript

## Installation

```bash
git clone https://github.com/tejasrahane123-eng/STARFLASH.git
cd STARFLASH
pip install -r requirements.txt
python web_app.py
```

Open: `http://127.0.0.1:5000`
