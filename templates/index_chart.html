Help & Quick Guide

How to use the app
How do I start a session?
Open Live Monitoring and click Start Session. The timer and attention metrics will begin updating from the camera data.
What counts as distraction?
The current prototype marks a student as distracted when the configured face-direction or eye-closure condition remains active long enough to cross its backend threshold.
Why is the camera not showing?
Make sure the Flask app is running, the camera is available to the computer, and no other application is currently using the camera. Refresh the app after checking.
How do I use Remote Demo?
Open Remote Demo or share the same /join link with multiple students. Each student enters a name or roll number and clicks Join with Camera. Every connected student is shown separately on the dashboard.
What do Search and Session Report show?
Search filters currently detected students. Session Report summarizes the current session duration, focus percentage, total distractions, and student-wise status.
What is Storage Room?
Storage Room keeps a persistent copy of student session reports. A report is saved when a student leaves, when the presenter ends the session, or when the session is reset. It stores duration, attention, last direction, distraction time, distraction percentage, and distraction count.

About STARFLASH
STARFLASH is an AI-powered student attention monitoring system designed to help understand focus and distraction during classroom or study sessions. It uses computer vision, facial landmarks, head-direction analysis, and eye-state detection to provide live attention insights through an interactive dashboard.
The system also supports remote student participation, session reports, and a Storage Room for keeping completed session records for later reference.
